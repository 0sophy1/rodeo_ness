# rodeo-ness

**Rodeo-algorithm steady-state preparation for open quantum systems.**

[![License: MIT][mit-shield]][mit] [![Docs License: CC BY 4.0][cc-by-shield]][cc-by]

[mit]: https://opensource.org/licenses/MIT
[mit-shield]: https://img.shields.io/badge/Code-MIT-blue.svg

Reference implementation and figure-reproduction notebooks for the paper
*Complexity Analysis and Efficient Implementation of the Rodeo Algorithm for
Steady-State Preparation*.

The package builds the Hermitian embedding of a vectorized Liouvillian, applies
the Rodeo and phase-estimation zero-sector filters, and reproduces every
quantitative figure in the paper. The central finding: the controlled-evolution
**spectral separation** `g = min_{j≠0,1}|φ_j|` (the smallest nonzero singular
value of the Liouvillian) is the single variable that governs whether Rodeo
filtering is cheaper than the phase-estimation realization — and the Rodeo
advantage grows with `g`.

## Installation

```bash
git clone https://github.com/0sophy1/rodeo-ness.git
cd rodeo-ness
pip install -e .
```

Optional extras:

```bash
pip install -e ".[circuit]"   # Qiskit + Aer, for the circuit-validation notebook
pip install -e ".[docs]"      # Jupyter, for running/building the notebooks
pip install -e ".[test]"      # pytest, for the test suite
```

Core dependencies are only `numpy`, `scipy`, and `matplotlib`. Qiskit is needed
**only** for notebook 06 (circuit-level validation); that notebook falls back to
an exact-filter reference if Qiskit is absent.

## Quickstart

```python
import numpy as np
import rodeo_ness as rn

# Single-spin benchmark (Ramusat & Savona): g = 1/2 for all h
L = rn.single_spin_liouvillian(h=0.5)
print("g       =", rn.spectral_separation(L))   # 0.5
print("g_decay =", rn.decay_rate(L))            # 0.5
rho = rn.steady_state(L)
print("<sz>    =", np.real(np.trace(rho @ np.diag([1, -1]))))  # -1/3

# Cost ratio at fixed controlled-evolution depth (>1 means Rodeo is cheaper)
print("G_QPE / G_Rodeo =", rn.cost_ratio(L, total_depth=15))

# Growing the chain closes g, so the Rodeo advantage shrinks
for N in [1, 2, 3, 4]:
    g = rn.spectral_separation(rn.tfim_liouvillian(N, J=0.0, gamma=1.0))
    print(f"N={N}: g={g:.3f}")
```

## Reproducing the paper figures

There is **one notebook per figure** in `docs/notebooks/`, plus a `00_quickstart`
tutorial. Start with the quick start for a map of the whole suite, then open any figure.
Each notebook explains the physics in more depth than the paper caption and writes its
PDF next to itself. Run them with Jupyter, or non-interactively:

```bash
jupyter nbconvert --to notebook --execute --inplace docs/notebooks/*.ipynb
```

**`00_quickstart.ipynb`** — model, filters, core API, and the figure map below.

The figures fall into three groups by what model they use and what engine generates
them. Numbering matches the final manuscript (main text Fig 1–7, supplement Fig S1–S4).

*Group A — single-spin benchmark (engine: `reproduce/core/`)*

| Notebook | Figure | Reproduces |
|---|---|---|
| `Figure01_cost.ipynb`        | 1 | depth vs target precision: QPE power law vs Rodeo log (2 panels) |
| `Figure02_obs_error.ipynb`   | 2 | single-shot observable error vs depth |
| `Figure04_observables.ipynb` | 4 | NESS recovery, 2×2 grid over `h` (Appendix B) |

*Group B — dissipative-TFIM separation sweep (engine: `rodeo_ness`)*

| Notebook | Figure | Reproduces |
|---|---|---|
| `Figure03_cost_vs_g.ipynb`   | 3 | cost ratio collapses onto `g`, grows with `g` (main result) |
| `Figure05_collapse.ipynb`    | 5 | decay-rate scatter + variance explained by each variable (`g`=0.95) — App. C.1 |
| `Figure06_interacting.ipynb` | 6 | 2×2 over `J`, four fixed `g` per panel: `g` (not `J`) sets the advantage — App. C.2 |
| `Figure07_density.ipynb`     | 7 | spectral density is a subleading, saturating effect — App. C.3 |

*Group C — circuit-level validation (engine: `rodeo_ness` + Qiskit/Aer; supplement)*

| Notebook | Figure | Reproduces |
|---|---|---|
| `FigureS1_dynamic_circuit.ipynb` | S1 | compiled dynamic Rodeo circuit |
| `FigureS2_trotter.ipynb`         | S2 | Trotter decomposition (9 Pauli terms) |
| `FigureS3_aer_convergence.ipynb` | S3 | AerSimulator convergence to NESS (empirical error bars) |
| `FigureS4_aer_cycle_saving.ipynb`| S4 | gate-level early-abort saving (exact curve + Aer; rises to ~43%) |

> Dropped from the final manuscript and moved to `docs/notebooks/_unused/`:
> `Figure02_restart` (restart overhead) and `Figure13_two_gaps` (`g`↔`g_decay` / encoding).
> Their PDFs are under `docs/figures/_unused/`.

Caption blocks for every figure (organised as main 1–7 / supplement S1–S4, with the
three draft-text discrepancies flagged at the top) are in
`paper_figure_updates/captions.tex`; see also `paper_figure_updates/UPDATES.md`.

## Circuit-level validation (Figures 8 & 9)

Figures 8 (convergence of the post-selected `<sigma_z>` to the exact NESS) and 9
(gate-level early-abort cycle saving) are produced by running the compiled dynamic
Rodeo circuit on a noiseless `AerSimulator`. The circuit builders and the
post-selection / ratio reconstruction live in `rodeo_ness.circuits`; the embedding
`M` is taken from `rodeo_ness.liouvillian` (bit-identical to the hardware notebook).

```bash
pip install "rodeo_ness[circuit]"
python -m reproduce.circuits.run_aer_validation   # writes Figs 8, 9 + aer_validation_data.csv
```

The `docs/notebooks/Figure08_*` and `Figure09_*` notebooks call the same module.
